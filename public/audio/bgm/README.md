# Background Music (BGM) Directory

Place your `.mp3`, `.ogg`, or `.wav` soundtrack files here according to `src/data/audioManifest.ts`:

- `menu_theme.mp3` (Main menu music)
- `campaign_map.mp3` (Campaign map & logistics screen)
- `combat_action.mp3` (Active battle canvas music)
- `victory_theme.mp3` (Victory theme)
- `game_over.mp3` (Game over theme)
