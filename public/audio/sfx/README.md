# Sound Effects (SFX) Directory

Place your `.mp3`, `.ogg`, or `.wav` sound effects here according to `src/data/audioManifest.ts`:

- `click.mp3` (UI button clicks)
- `sword1.mp3`, `sword2.mp3`, `sword3.mp3` (Melee / sword strikes)
- `bow1.mp3`, `bow2.mp3` (Archer attacks)
- `magic1.mp3`, `magic2.mp3` (Mage spells)
- `unit_spawn.mp3` (Deploying units)
- `death1.mp3`, `death2.mp3` (Unit death sounds)
- `victory_fanfare.mp3` (Battle won)
- `defeat_horn.mp3` (Battle lost)
- `coin.mp3` (Gold / purchase sound)
- `levelup.mp3` (Perk / upgrade sound)
- `error.mp3` (Invalid action / error sound)
